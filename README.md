# Sprite Sheet Editor

브라우저에서 바로 실행할 수 있는 스프라이트 시트 편집기입니다.

## 기능

- 이미지 업로드
- 프레임 크기, 행/열, 오프셋, 간격 기반 스프라이트 시트 분할
- 투명/단색 여백 기준 자동 분할값 추정
- 원본 이미지 위 프레임 영역 오버레이 표시
- 프레임 선택
- 선택 프레임 또는 전체 프레임을 출력 순서에 추가
- 출력 프레임 드래그 앤 드롭 재배치
- FPS 설정 후 애니메이션 재생 미리보기
- 출력 열 수 지정 후 PNG 스프라이트 시트 내보내기

## 실행 방법

별도 빌드 과정이 없습니다.

```bash
# 저장소 클론 후
open index.html
```

또는 VS Code Live Server 같은 정적 서버로 실행해도 됩니다.

```bash
python3 -m http.server 5173
```

브라우저에서 `http://localhost:5173` 접속.

## 사용 흐름

1. 이미지 업로드
2. 자동 추정값 확인
3. 프레임 너비/높이, 행/열, 오프셋, 간격 보정
4. `프레임 나누기` 클릭
5. 분할된 프레임을 선택해서 출력 순서에 추가
6. 출력 순서에서 드래그 앤 드롭으로 재배치
7. `재생`으로 애니메이션 확인
8. `PNG 내보내기`로 새 스프라이트 시트 저장

## 자동 추정 한계

현재 자동 추정은 브라우저 Canvas API 기반입니다. 투명 배경 또는 단색 배경의 여백을 기준으로 유효 영역을 잡고, 흔히 쓰는 프레임 크기 후보를 선택합니다.

복잡한 배경, 프레임 사이 여백이 불규칙한 시트, 여러 캐릭터가 섞인 이미지에서는 수동 보정이 필요합니다.

## 파일 구성

```text
index.html      # 화면 구조
styles.css      # UI 스타일
src/app.js      # 업로드, 분할, 재생, 재배치, 내보내기 로직
```
