# Sprite Tool Studio

브라우저에서 바로 실행할 수 있는 로컬 스프라이트/미디어 편집 도구입니다.

이미지, 스프라이트 시트, GIF, 영상, 오디오를 서버 업로드 없이 브라우저에서 처리하는 것을 목표로 합니다. 현재는 스프라이트 시트 편집기, 영상/GIF 변환, 음원 변환, 배경색 제거 도구를 포함합니다.

## 주요 기능

### 스프라이트 시트 편집기

- 이미지 업로드
- 프레임 너비/높이, 행/열, 오프셋, 간격 기반 분할
- 전체 이미지 균등 분할
- 원본 이미지 위 프레임 영역 오버레이 표시
- 선택 프레임 또는 전체 프레임을 출력 순서에 추가
- 출력 프레임 드래그 앤 드롭 재배치
- 출력 열 수 지정
- FPS 설정 후 애니메이션 재생 미리보기
- 프레임 위치 보정
- 프레임 박스 크기 보정
- 픽셀 영역 기준 가운데 정렬
- 배경색/투명 배경 옵션
- PNG 스프라이트 시트 내보내기
- GIF 애니메이션 내보내기
- TGA 이미지 업로드 지원

### 영상 / GIF 변환

- 영상 파일을 GIF로 변환
- GIF 파일을 WebM 영상으로 변환
- 프레임 추출 기반 변환
- FPS, 크기, 품질 관련 설정 지원

### 음원 변환

- 브라우저에서 지원하는 오디오 포맷 변환
- WAV, MP3, WebM/Ogg/M4A 등 브라우저 지원 범위 내에서 처리
- 변환 결과 다운로드

### 배경색 제거

이미지 파일을 올린 뒤 특정 배경색을 선택해 해당 색상 픽셀을 투명 처리하는 도구입니다.

- 그림 파일 업로드
- 색상 피커로 제거할 색상 선택
- 원본 미리보기 클릭/터치로 픽셀 색상 추출
- 허용 오차 조절
- 제거 강도 선택: 정밀, 기본, 깔끔, 강하게
- 가장자리 자잘한 픽셀 정리 옵션
- 결과 미리보기 배경 선택: 체커보드, 흰색, 어두운색, 기본 투명
- 결과 PNG 다운로드

#### 배경색 제거 미리보기 조작

- 원본/결과 미리보기 터치 드래그 이동
- 두 손가락 핀치 줌
- 미리보기 위치 초기화
- 이미지 새 업로드 시 실제 픽셀 영역으로 자동 이동
- 색상/오차/강도 변경 후에도 사용자가 맞춘 미리보기 위치 유지

#### 결과 복원 브러시

배경 제거 후 잘못 지워진 부분을 결과 화면에서 직접 복원할 수 있습니다.

- `결과 복원 브러시` 켜기
- 결과 미리보기에서 손가락 또는 마우스로 문지르기
- 문지른 영역만 원본 픽셀로 복원
- 브러시 크기 조절
- 결과를 원본으로 전체 복원
- 브러시 작업 후 다운로드 PNG 자동 갱신

복원 브러시가 켜져 있을 때는 결과 화면에서 그리기 동작이 우선됩니다. 미리보기 이동이나 핀치 줌을 사용하려면 복원 브러시를 끄면 됩니다.

## 실행 방법

별도 빌드 과정이 없습니다.

정적 서버 실행을 권장합니다.

```bash
python3 -m http.server 5173
```

브라우저에서 아래 주소로 접속합니다.

```text
http://localhost:5173
```

간단히 파일을 직접 열 수도 있습니다.

```bash
open index.html
```

다만 일부 브라우저에서는 로컬 파일 실행 시 미디어 처리, 워커, 다운로드 동작이 제한될 수 있으므로 정적 서버 방식이 더 안전합니다.

## 기본 사용 흐름

### 스프라이트 시트 편집

1. 스프라이트 이미지 업로드
2. 자동 추정값 확인
3. 프레임 너비/높이, 행/열, 오프셋, 간격 보정
4. `프레임 나누기` 클릭
5. 분할된 프레임을 선택해서 출력 순서에 추가
6. 출력 순서에서 드래그 앤 드롭으로 재배치
7. `재생`으로 애니메이션 확인
8. PNG 또는 GIF로 내보내기

### 배경색 제거

1. `배경색 제거` 메뉴 선택
2. 그림 파일 업로드
3. 색상 피커 또는 원본 미리보기 클릭으로 제거할 색상 선택
4. 허용 오차와 제거 강도 조절
5. 결과 미리보기 확인
6. 필요한 경우 결과 복원 브러시로 잘못 지워진 부분 복원
7. PNG 다운로드

## 자동 추정 한계

스프라이트 분할 자동 추정은 이미지 크기와 흔히 쓰는 프레임 크기 후보를 기준으로 동작합니다.

복잡한 배경, 불규칙한 프레임 간격, 여러 캐릭터가 섞인 이미지, 프레임마다 크기가 다른 시트에서는 수동 보정이 필요합니다.

배경색 제거는 선택 색상과 허용 오차를 기준으로 픽셀을 투명 처리합니다. JPEG처럼 압축 노이즈가 있거나 배경색이 미세하게 여러 색으로 섞인 이미지에서는 허용 오차와 제거 강도를 조정해야 합니다.

## 파일 구성

```text
index.html                              # 화면 구조와 스크립트 로드
styles.css                              # 기본 UI 스타일
tool-shell.css                          # 도구 화면/사이드 메뉴 스타일
src/app.js                              # 스프라이트 업로드, 분할, 재생, PNG 내보내기
src/ui-shell.js                         # 도구 메뉴/화면 전환, 배경색 제거 기본 UI
src/grid-layout.js                      # 프레임 그리드 보정, 배경 제거 보조 스크립트 로드
src/frame-overflow-adjustment.js        # 프레임 위치/박스 보정
src/tga-support.js                      # TGA 이미지 지원
src/sprite-gif-encoder.js               # 스프라이트 GIF 인코더
src/sprite-gif-export.js                # 스프라이트 GIF 내보내기
src/media-converter.js                  # 영상/GIF 변환
src/audio-converter.js                  # 오디오 변환
src/background-remover-autopan.js       # 배경 제거 미리보기 이동/자동 위치/핀치 줌
src/background-remover-restore-brush.js # 결과 복원 브러시
src/vendor/                             # 외부/벤더 스크립트
```

## 개발 메모

- 현재 프로젝트는 빌드 도구 없이 정적 HTML/CSS/JS로 동작합니다.
- 기능별 스크립트는 전역 DOM 요소와 Canvas API를 중심으로 연결됩니다.
- 배경색 제거 결과는 Canvas RGBA 픽셀 데이터를 직접 수정해서 알파 채널을 0으로 만듭니다.
- 복원 브러시는 원본 캔버스 픽셀을 결과 캔버스에 다시 복사하는 방식입니다.
- 미리보기 이동/핀치 줌은 결과 이미지 데이터 자체를 바꾸지 않고, 캔버스 표시 레이어와 스크롤 위치만 조정합니다.
