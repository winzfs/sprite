# Sprite Tool Studio

브라우저에서 바로 실행할 수 있는 로컬 스프라이트/미디어 편집 도구입니다.

이미지, 스프라이트 시트, GIF, 영상, 오디오를 서버 업로드 없이 브라우저에서 처리하는 것을 목표로 합니다. 현재는 스프라이트 시트 편집기, 영상/GIF 변환, 음원 변환, 배경색 제거, 픽셀아트 변환, 효과음 제작기 도구를 포함합니다.

## 주요 기능

### 스프라이트 시트 편집기

- 이미지 업로드
- 프레임 너비/높이, 행/열, 오프셋, 간격 기반 분할
- 전체 이미지 균등 분할
- 원본 이미지 위 프레임 영역 오버레이 표시
- 선택 프레임 또는 전체 프레임을 출력 순서에 추가
- 출력 프레임 드래그 앤 드롭 재배치
- 출력 열 수 지정
- FPS 설정 후 애니메이션 재생 미리보기
- 프레임 위치 보정
- 프레임 박스 크기 보정
- 픽셀 영역 기준 가운데 정렬
- 배경색/투명 배경 옵션
- PNG 스프라이트 시트 내보내기
- GIF 애니메이션 내보내기
- TGA 이미지 업로드 지원

### 영상 / GIF 변환

- 영상 파일을 GIF로 변환
- GIF 파일을 WebM 영상으로 변환
- 프레임 추출 기반 변환
- FPS, 크기, 품질 관련 설정 지원

### 음원 변환

- 브라우저에서 지원하는 오디오 포맷 변환
- WAV, MP3, WebM/Ogg/M4A 등 브라우저 지원 범위 내에서 처리
- 변환 결과 다운로드

### 효과음 제작기

Web Audio 기반으로 게임, 웹 UI, 디스코드 봇, 알림음에 사용할 짧은 효과음을 직접 생성하는 도구입니다.

- 앱형 전용 UI
- 프리셋 카드 선택
- 실시간 파라미터 조절
- 미리듣기
- 재생 중 정지
- 랜덤 효과음 생성
- 파형 미리보기
- WAV 다운로드

지원 프리셋 예시:

- UI 클릭
- 확인 / 취소
- 알림
- 코인 획득
- 점프 / 착지
- 가벼운 타격 / 강한 타격
- 폭발
- 레이저
- 파워업 / 파워다운
- 힐
- 마법 시전
- 강화 성공 / 강화 실패
- 경고
- 글리치
- 메뉴 열림 / 메뉴 닫힘
- 아이템 획득
- 타이핑
- 포탈

조절 가능한 값:

- 파형: Sine, Square, Triangle, Sawtooth, Noise
- 파일 이름
- 길이
- 볼륨
- 시작 피치 / 끝 피치
- 어택 / 감쇠 / 서스테인 / 릴리즈
- 노이즈
- 필터
- 비브라토 깊이 / 속도
- 펀치감
- 비트크러시
- 아르페지오

### 픽셀아트 변환

사진이나 그림을 낮은 해상도, 제한 팔레트, 디더링, 윤곽 강조, 형태 보존 보정을 거쳐 픽셀아트풍 PNG로 변환하는 도구입니다.

기본 픽셀아트 변환은 꺼진 보조 모드 없이 동작합니다. 추가로 `스마트 원형 보존` 또는 `초저해상도 디테일 압축`을 켜면 해당 모드가 변환 버튼 실행을 가로채서 전용 알고리즘으로 결과를 생성합니다.

- 이미지 파일 업로드
- 목표 해상도 지정
- 비율 유지 옵션
- 프리셋 선택: 깔끔한 게임 스프라이트, 부드러운 픽셀 일러스트, 레트로 콘솔풍, Chunky Pixel
- 색상 수 제한
- 디더링 선택: 없음, Ordered Bayer, Floyd-Steinberg
- 대비/채도 보정
- 윤곽 강조
- 형태 단순화
- 결과 배경 선택: 투명 유지, 흰색, 검정, 회색
- 확대 배율 지정
- 추출 팔레트 표시 및 HEX 복사
- PNG 다운로드

#### 픽셀아트 보조 모드

보조 모드는 기본적으로 꺼진 상태로 시작합니다.

- `스마트 원형 보존`: 원본 이미지의 실루엣, 큰 명암 덩어리, 대표색 흐름을 우선 보존합니다.
- `초저해상도 디테일 압축`: 32×32, 64×64처럼 낮은 해상도에서 사라지기 쉬운 눈, 입, 경계, 작은 명암 특징을 픽셀 패턴으로 압축해 보존합니다.
- 두 모드가 모두 켜져 있으면 `초저해상도 디테일 압축`이 우선 적용됩니다.
- 두 모드가 모두 꺼져 있으면 기본 픽셀아트 변환기가 실행됩니다.

관련 옵션:

- 원형 보존
- 디테일 강도
- 미세 디테일
- 명암 패턴
- 특징점 강조
- 선명도
- 형태 단순화

#### 픽셀아트 플로팅 설정 패널

`픽셀아트 변환` 화면에서는 미리보기와 설정을 오가야 하는 불편을 줄이기 위해 `⚙️ 픽셀 설정` 플로팅 패널을 제공합니다.

- 미리보기 화면 위에서 빠르게 설정 변경
- 너비/높이, 색상 수, 대비/채도, 윤곽, 확대 배율 조절
- 스마트 원형 보존 ON/OFF
- 초저해상도 디테일 압축 ON/OFF
- 미세 디테일, 명암 패턴, 특징점 강조 조절
- 32 추천 / 64 추천 빠른 설정
- 자동 변환 ON/OFF

플로팅 패널은 실제 픽셀아트 보조 모드 옵션이 생성된 뒤에만 표시되도록 되어 있습니다. 체크박스는 원본 옵션과 1:1로 동기화됩니다.

### 배경색 제거

이미지 파일을 올린 뒤 특정 배경색을 선택해 해당 색상 픽셀을 투명 처리하는 도구입니다.

- 그림 파일 업로드
- 색상 피커로 제거할 색상 선택
- 원본 미리보기 클릭/터치로 픽셀 색상 추출
- 허용 오차 조절
- 제거 강도 선택: 정밀, 기본, 깔끔, 강하게
- 가장자리 자잘한 픽셀 정리 옵션
- 결과 미리보기 배경 선택: 체커보드, 흰색, 어두운색, 기본 투명
- 결과 PNG 다운로드

#### 배경색 제거 미리보기 조작

- 원본/결과 미리보기 터치 드래그 이동
- 두 손가락 핀치 줌
- 미리보기 위치 초기화
- 이미지 새 업로드 시 실제 픽셀 영역으로 자동 이동
- 색상/오차/강도 변경 후에도 사용자가 맞춘 미리보기 위치 유지

#### 결과 복원 브러시

배경 제거 후 잘못 지워진 부분을 결과 화면에서 직접 복원할 수 있습니다.

- `결과 복원 브러시` 켜기
- 결과 미리보기에서 손가락 또는 마우스로 문지르기
- 문지른 영역만 원본 픽셀로 복원
- 브러시 크기 조절
- 결과를 원본으로 전체 복원
- 브러시 작업 후 다운로드 PNG 자동 갱신

복원 브러시가 켜져 있을 때는 결과 화면에서 그리기 동작이 우선됩니다. 미리보기 이동이나 핀치 줌을 사용하려면 복원 브러시를 끄면 됩니다.

## 실행 방법

별도 빌드 과정이 없습니다.

정적 서버 실행을 권장합니다.

```bash
python3 -m http.server 5173
```

브라우저에서 아래 주소로 접속합니다.

```text
http://localhost:5173
```

간단히 파일을 직접 열 수도 있습니다.

```bash
open index.html
```

다만 일부 브라우저에서는 로컬 파일 실행 시 미디어 처리, 워커, 다운로드 동작이 제한될 수 있으므로 정적 서버 방식이 더 안전합니다.

## 기본 사용 흐름

### 스프라이트 시트 편집

1. 스프라이트 이미지 업로드
2. 자동 추정값 확인
3. 프레임 너비/높이, 행/열, 오프셋, 간격 보정
4. `프레임 나누기` 클릭
5. 분할된 프레임을 선택해서 출력 순서에 추가
6. 출력 순서에서 드래그 앤 드롭으로 재배치
7. `재생`으로 애니메이션 확인
8. PNG 또는 GIF로 내보내기

### 효과음 제작

1. `효과음 제작기` 메뉴 선택
2. 프리셋 카드 선택
3. 길이, 피치, 볼륨, 노이즈, 필터 등 조절
4. `미리듣기`로 확인
5. 필요하면 `랜덤`으로 새 효과음 생성
6. WAV 다운로드

### 픽셀아트 변환

1. `픽셀아트 변환` 메뉴 선택
2. 이미지 파일 업로드
3. 프리셋 또는 목표 해상도 지정
4. 기본 변환만 사용할지, 스마트/초저해상도 보조 모드를 켤지 선택
5. 색상 수, 디더링, 대비/채도, 윤곽, 형태 보존 관련 값을 조절
6. 결과 미리보기와 팔레트 확인
7. 필요하면 `⚙️ 픽셀 설정` 플로팅 패널에서 미리보기와 함께 세부 조정
8. PNG 다운로드

### 배경색 제거

1. `배경색 제거` 메뉴 선택
2. 그림 파일 업로드
3. 색상 피커 또는 원본 미리보기 클릭으로 제거할 색상 선택
4. 허용 오차와 제거 강도 조절
5. 결과 미리보기 확인
6. 필요한 경우 결과 복원 브러시로 잘못 지워진 부분 복원
7. PNG 다운로드

## 자동 추정 및 변환 한계

스프라이트 분할 자동 추정은 이미지 크기와 흔히 쓰는 프레임 크기 후보를 기준으로 동작합니다.

복잡한 배경, 불규칙한 프레임 간격, 여러 캐릭터가 섞인 이미지, 프레임마다 크기가 다른 시트에서는 수동 보정이 필요합니다.

픽셀아트 변환은 자동 보정 도구입니다. 수작업 픽셀아트처럼 의도적으로 정리된 결과와는 차이가 있을 수 있습니다. 특히 32×32처럼 매우 낮은 해상도는 전체 픽셀 수가 적어 원본의 모든 디테일을 그대로 보존할 수 없습니다. 대신 스마트/초저해상도 모드는 실루엣, 명암, 특징점을 더 읽히게 압축하는 방향으로 동작합니다.

효과음 제작기는 Web Audio로 합성한 짧은 사운드를 WAV로 저장합니다. 실제 악기 샘플 기반이 아니라 합성음 기반이므로 레트로/게임/UI 효과음 제작에 더 적합합니다.

배경색 제거는 선택 색상과 허용 오차를 기준으로 픽셀을 투명 처리합니다. JPEG처럼 압축 노이즈가 있거나 배경색이 미세하게 여러 색으로 섞인 이미지에서는 허용 오차와 제거 강도를 조정해야 합니다.

## 캐시 문제 해결

이 프로젝트는 빌드 도구 없이 정적 파일을 직접 로드합니다. 새 기능을 반영했는데 화면이 예전 상태로 보이면 브라우저 캐시가 남아 있을 수 있습니다.

- 브라우저 탭을 완전히 닫고 다시 열기
- 주소 뒤에 `?fresh=1` 같은 임의 쿼리 붙이기
- 정적 서버를 다시 실행하기
- 모바일 브라우저에서는 앱을 완전히 종료 후 재실행하기

## 파일 구성

```text
index.html                              # 화면 구조와 스크립트 로드
styles.css                              # 기본 UI 스타일
tool-shell.css                          # 도구 화면/사이드 메뉴 스타일
src/app.js                              # 스프라이트 업로드, 분할, 재생, PNG 내보내기
src/ui-shell.js                         # 도구 메뉴/화면 전환, 배경색 제거 기본 UI
src/grid-layout.js                      # 프레임 그리드 보정, 보조 도구 스크립트 순차 로드
src/frame-overflow-adjustment.js        # 프레임 위치/박스 보정
src/tga-support.js                      # TGA 이미지 지원
src/sprite-gif-encoder.js               # 스프라이트 GIF 인코더
src/sprite-gif-export.js                # 스프라이트 GIF 내보내기
src/media-converter.js                  # 영상/GIF 변환
src/audio-converter.js                  # 오디오 변환
src/sfx-maker.js                        # 효과음 제작기
src/pixel-art-converter.js              # 기본 이미지 → 픽셀아트 변환
src/pixel-art-unified-modes.js          # 스마트 원형 보존 / 초저해상도 디테일 압축 통합 처리
src/pixel-art-floating-controls.js      # 픽셀아트 플로팅 설정 패널
src/background-remover-autopan.js       # 배경 제거 미리보기 이동/자동 위치/핀치 줌
src/background-remover-restore-brush.js # 결과 복원 브러시
src/vendor/                             # 외부/벤더 스크립트
```

참고: 이전 실험용 픽셀아트 보조 스크립트였던 `pixel-art-smart-detail.js`, `pixel-art-ultra-detail.js`, `pixel-art-mode-guard.js`, `pixel-art-option-effects.js`는 더 이상 로드하지 않습니다. 현재 실행 경로는 `pixel-art-converter.js`와 `pixel-art-unified-modes.js` 중심입니다.

## 개발 메모

- 현재 프로젝트는 빌드 도구 없이 정적 HTML/CSS/JS로 동작합니다.
- 기능별 스크립트는 전역 DOM 요소와 Canvas API/Web Audio API를 중심으로 연결됩니다.
- `grid-layout.js`는 보조 스크립트를 순차 로드하여 픽셀아트 통합 모드, 플로팅 패널, 효과음 제작기를 초기화합니다.
- 기본 픽셀아트 변환은 Canvas 축소, 색상 보정, 팔레트 추출, 팔레트 양자화, 디더링, 윤곽 보정을 조합합니다.
- 스마트/초저해상도 모드는 통합 모드 스크립트에서 실행 우선순위를 관리합니다.
- 효과음 제작기는 Web Audio 합성 결과를 16-bit PCM WAV로 인코딩합니다.
- 배경색 제거 결과는 Canvas RGBA 픽셀 데이터를 직접 수정해서 알파 채널을 0으로 만듭니다.
- 복원 브러시는 원본 캔버스 픽셀을 결과 캔버스에 다시 복사하는 방식입니다.
- 미리보기 이동/핀치 줌은 결과 이미지 데이터 자체를 바꾸지 않고, 캔버스 표시 레이어와 스크롤 위치만 조정합니다.
